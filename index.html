[01] // system architecture — arc42 / c4

A brain, a memory,
a pair of hands.

Three cooperating layers separate strategic reasoning from persistent knowledge and low-level tactical execution.

core reasoning engine

ArgusBrain — LangGraph ReAct controller

A dual-mode StateGraph agent executing a strict Thought → Action → Observation cycle, with automated JSON and plain-text parsing fallback when models drift off-schema.

  • WhiteRabbitNeo-V3-7B via local Ollama runtime
  • Dual-mode agent — structured JSON & text fallback
Thought reason & plan
Action invoke tool
Observation parse result
observations feed the next reasoning step
02 persistent intelligence

RAG & SQLite blackboard

Static technique knowledge from a FAISS vector store fused with live session state — targets, findings and entity relations persisted across the whole engagement.

  • FAISS + nomic-embed-text embeddings
  • SQLite schema: targets / findings / relations
03 tactical execution

WSLBridge execution layer

Every command lands in an isolated Kali Linux WSL container through subprocess / SSH — the host OS stays clean, tools self-heal when missing.

  • Subprocess & SSH Kali bridge
  • Auto self-healing (apt / pip)
04 verification & safety

Reflective verification & ZERO-APT

Pre- and post-execution reflection kills false positives and WAF traps before they reach the report. STIX 2.0 attacker–defender–judge cycles stress-test every conclusion.

  • Pre / post execution reflection pass
  • Attacker–defender–judge simulation cycles

[03] // tool registry & services

Twelve services,
one orchestrator.

Specialized sub-services orchestrated by ArgusBrain through a single Tool Registry facade.

ReconService

Multi-tool OSINT orchestration, subdomain enumeration and WAF profiling.

VulnerabilityScanners

Nmap port discovery chained into Nuclei template-based vulnerability scans.

CrawlerService

Deep endpoint discovery with Katana and headless asset spidering.

EvasionService

Payload obfuscation, encoding strategies and adaptive WAF bypass techniques.

PayloadSuggester

Context-aware exploit payloads generated from live RAG memory hits.

SelfHealingService

Detects broken or missing tooling inside Kali and repairs it autonomously.
